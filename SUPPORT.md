# Support

Use GitHub issues for technical support, bug reports, feature requests, and documentation gaps.

## Where to ask

| Request type                                                | Where to open it       |
| ----------------------------------------------------------- | ---------------------- |
| Agronomic data, forms, ETL, metadata                        | `e-agrology`           |
| Monitoring indicators, ML or crop modeling, geospatial data | `hfms`                 |
| Advisory UI, workflows, rules, content                      | `agrotutor`            |
| Prompts, agents, LLM evaluation                             | `ai-orchestration`     |
| Coding rules, setup, release, ADRs                          | `engineering-playbook` |
| GitHub templates and organization defaults                  | `.github`              |

## Good support request

Include:

- Repository name
- Environment
- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs or screenshots
- Data sample, if safe to share
