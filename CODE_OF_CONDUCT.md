# Code of Conduct

The `eAg-HFMS-AgroTutor` project expects professional, respectful, and constructive collaboration.

## Expected behavior

- Be respectful in issues, pull requests, reviews, meetings, and chat.
- Focus criticism on the work, not the person.
- Give clear technical feedback with actionable suggestions.
- Ask for clarification when requirements are ambiguous.
- Respect differences in language, background, timezone, and expertise.
- Credit contributors for their work.

## Unacceptable behavior

- Harassment, insults, intimidation, or discriminatory language.
- Public shaming of contributors.
- Dismissing review feedback without explanation.
- Sharing private data, credentials, or restricted project information.
- Repeatedly bypassing agreed engineering processes.

## Enforcement

Project maintainers may warn contributors, restrict repository access, or escalate issues to project leadership when behavior harms the project or team.

Report concerns to the repository maintainers or project technical lead.
