# eAg-HFMS-AgroTutor GitHub Defaults

This repository contains organization-wide GitHub defaults for the `eAg-HFMS-AgroTutor` organization.

It is intentionally lightweight. Detailed engineering standards are maintained in the `engineering-playbook` repository.

## What belongs here

- Organization profile
- Default contribution guide
- Pull request template
- Issue templates
- Security policy
- Support policy
- Reusable workflow templates

## What does not belong here

- Product code
- Data pipelines
- Application documentation
- Architecture decisions
- Secrets or credentials

## Platform repository map

| Repository             | Purpose                                                                  |
| ---------------------- | ------------------------------------------------------------------------ |
| `.github`              | Organization defaults and GitHub templates                               |
| `engineering-playbook` | Engineering standards, setup, governance, testing, releases, ADRs        |
| `e-agrology`           | Agronomic data workflows, forms, ETL, FAIR metadata                      |
| `hfms`                 | High-frequency monitoring pipelines, data cube, feature store, dashboard |
| `agrotutor`            | Advisory product, user flows, rules, content, frontend                   |
| `ai-orchestration`     | LLM orchestration, tools, prompts, evaluations, guardrails               |
