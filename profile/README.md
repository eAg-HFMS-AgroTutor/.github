# eAg-HFMS-AgroTutor

**eAg-HFMS-AgroTutor** is organized around four product modules and two governance repositories.

## Product modules

| Repository         | Scope                                                           |
| ------------------ | --------------------------------------------------------------- |
| `e-agrology`       | Agronomic data collection, ETL, metadata, FAIR publication      |
| `hfms`             | High-frequency monitoring system, indicators, plot intelligence |
| `agrotutor`        | Advisory platform, user workflows, rules, multilingual content  |
| `ai-orchestration` | Orchestration agent, subagents, prompt registry, guardrails     |

## Governance repositories

| Repository             | Scope                                                     |
| ---------------------- | --------------------------------------------------------- |
| `.github`              | Organization-wide GitHub defaults                         |
| `engineering-playbook` | Detailed engineering standards and architecture decisions |

## Contribution rule

All work must start from an issue, proceed through a feature branch, and be merged through a reviewed pull request.
